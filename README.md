
# Learnova | Платформа для подготовки к STEM олимпиадам

Этот проект представляет собой образовательную платформу для изучения STEM предметов и подготовки к олимпиадам.

## 🚀 Как запустить локально

1. **Установка зависимостей**:
   ```bash
   npm install
   ```

2. **Запуск сервера разработки**:
   ```bash
   npm run dev
   ```
   Приложение будет доступно по адресу [http://localhost:9002](http://localhost:9002).

## Структура проекта
- `src/app`: Страницы и лейауты (Next.js App Router).
- `src/components`: UI компоненты (ShadCN).
- `src/lib`: Утилиты и данные.


# VAcademi | Платформа для подготовки к STEM олимпиадам

Этот проект представляет собой образовательную платформу для изучения STEM предметов и подготовки к олимпиадам.

Описание новых разделов, настройки Firebase/AI и ограничения: [Изменения по списку](docs/improvements.md). Пример конфигурации — `.env.example`.

## 🚀 Как запустить локально

1. **Скачайте код**: Нажмите кнопку "Download" или "Export" в интерфейсе Firebase Studio, чтобы получить ZIP-архив с проектом. Распакуйте его в удобную папку.

2. **Установите Node.js**: Убедитесь, что у вас установлена Node.js (версия 18 или выше).

3. **Установка зависимостей**: Откройте терминал в папке проекта и выполните:
   ```bash
   npm install
   ```

4. **Запуск сервера разработки**:
   ```bash
   npm run dev
   ```
   Приложение будет доступно по адресу [http://localhost:9002](http://localhost:9002).

## Структура проекта
- `src/app`: Страницы и лейауты (Next.js App Router).
- `src/components`: UI компоненты (ShadCN).
- `src/lib`: Утилиты и данные.

## Русский и английский интерфейс

Переключатель RU / EN доступен на главной странице, в мобильном меню, в кабинете и в формах входа и регистрации. Выбор сохраняется на год в cookie `next-intl-locale` и действует при переходах между страницами. По умолчанию используется русский; неизвестное значение cookie также возвращает русский интерфейс. Адреса страниц остаются одинаковыми для обоих языков.

Переводы находятся в `src/i18n/messages/ru.json` и `en.json`. Для подстановок используется формат ICU: `{name}`, `{count}`. AI учитывает выбранный язык. Внешние PDF, видео и исходные учебные материалы сохраняют язык оригинала.

Проверка словарей, подстановок и ключей интерфейса: `npm run check:i18n`. Проверка типов: `npm run typecheck`.

## Настройка Groq AI
1. Скопируйте ключ из https://console.groq.com/keys.
2. Создайте файл `.env` рядом с `package.json`.
3. Добавьте в него:
   ```env
   GROQ_API_KEY=ваш_ключ
   ```
4. Перезапустите приложение.

# Изменения по списку

1. `/feedback`: форма на сайте с валидацией, email и номером обращения. Заявки сохраняются в Supabase (`tickets`). Уведомления Telegram необязательны; сбой уведомления не отменяет сохранение. Для уведомлений нужны `TELEGRAM_BOT_TOKEN` и документы `admin_config/{department}` с `chatIds`. Предметы используют идентификаторы бота: `math`, `cs`, `physics`, `chemistry`, `biology`. Ответ по email отправляется сотрудником поддержки; автоматическая отправка email из этой формы не реализована.
2. `/olympiads`: Кыргызстан и международные олимпиады, фильтры региона/предмета и поиск. Источники — сайты Министерства образования Кыргызстана и организаторов IMO, IPhO, IChO, IBO, IOI. Графики Кыргызстана 2025/26 помечены как прошлый сезон. Каталог не утверждает, что регистрация сейчас открыта. Данные статические и требуют обновления при публикации нового сезона.
3. `/courses`: четыре проверенных внешних видеокурса MIT OCW, встроенный плеер для прямых YouTube-ссылок. Каналы, плейлисты и поисковые ссылки открываются у источника. Учебные материалы MIT на английском, университетского уровня. Ранее добавленные материалы сохранены.
4. Добавлены 66 упражнений: 30 отдельных задач и 36 вариантов для отработки формул. Условия на русском. Они доступны в каталоге и в тренировках. Исправлены ответы в задачах про бинарный поиск и ненасыщенность углеводородов.
5. `/ai`: предмет, подсказка, проверка рассуждений, план подготовки, язык ответа RU/EN, ограничение длины вопроса и таймаут. Работает при настройке `GROQ_API_KEY`; без ключа показывается сообщение. Подсказки не подменяются имитацией AI.
6. RU/EN: сохранение языка в cookie, переключение на главной, в кабинете и авторизации. Перевод интерфейса не переводит автоматически учебные PDF, условия задач или внешние видео.
7. Регистрация создаёт ученический аккаунт. Выбор учителя переводит на `/teacher`, где нужно заполнить заявку (имя, организация, основание и рабочий контакт). До одобрения доступны только ученические возможности. `/dashboard/admin/teachers` показывает заявки доверенному администратору; после проверки через школу он подтверждает или отклоняет их. Сервер проверяет токен Supabase и одновременно `role: teacher` + `teacherStatus: approved` при доступе к подборкам. Самостоятельно записать эти поля через профиль нельзя; прежняя самостоятельно выбранная роль тоже не открывает доступ. Отклонённую заявку можно подать повторно. Управление классами и выдача подборок ученикам пока не реализованы.
8. `/practice`: случайная подборка, таймер (две минуты на задачу), проверка числовых/текстовых ответов, объяснения, повтор ошибок, переход к AI. Последний результат сохраняется локально в браузере. Баллы профиля начисляются через каталог задач, только после серверной проверки. Повторное решение не начисляет повторные баллы; обновление выполняется транзакцией.
9. Главная: данные реального каталога, кнопки перехода к практике и симуляторам, блок для учителей. Неподтверждённые цифры про количество учеников и процент успеха убраны.
10. Раздел команды подготовлен без вымышленных имён и фото. Персональный состав будет добавлен по предоставленному владельцем списку.
11. `/simulators`: бросок под углом, закон Ома и равновесие Харди — Вайнберга. Параметры, графика, результаты и задания для исследования; допущения каждой модели указаны.

## Настройка и проверка

Настройте Supabase по [инструкции перехода](supabase-migration.md). AI и Telegram имеют отдельные необязательные ключи. Секреты нельзя публиковать в клиентских переменных или коммитить.

В серверной переменной `ADMIN_UIDS` укажите UID доверенных администраторов из Supabase → Authentication → Users (через запятую), затем перезапустите или переопубликуйте приложение. Не добавляйте туда UID заявителей. Настройки Telegram и решения по заявкам защищены этим списком; Telegram chat ID сам по себе не даёт права администратора сайта.

Выполните SQL миграции до публикации: RLS закрывает прямой браузерный доступ к данным приложения; серверные API проверяют полномочия пользователя. Схема автоматически не устанавливается.

Команды: `npm run typecheck`, `node scripts/check-learning.cjs`, `node scripts/check-submissions.cjs`, `node scripts/check-teacher-access.cjs`, `npm run check:i18n`, `npm run build`.

Проверка интерфейса: главная → практика → завершить → повтор ошибок; симуляторы → изменить параметры → сбросить; олимпиады → поиск/фильтры → источник; RU/EN → обновить страницу; регистрация учителя → отправить заявку → администратор проверяет и подтверждает → обновить статус → сохранить подборку; обратная связь → отправить → проверить документ `tickets`. Последние два сценария требуют рабочей конфигурации Supabase. Реальное получение AI-ответа требует ключа Groq.

Проверка свободного ответа сравнивает с эталоном (регистронезависимо, поддерживает десятичную запятую). Это не проверка произвольных математических доказательств. Ответы каталога доступны клиенту для учебных разборов; платформа не предназначена для защищённых экзаменов.
